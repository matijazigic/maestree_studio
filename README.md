# Maestree — Behavior Tree Studio

**Maestree** is a visual studio for **behavior trees**. Design and edit trees,
then connect to a running tree to **live-debug** it — watch nodes tick in real
time, set breakpoints, inspect the blackboard and ports, and record sessions to
replay later. It works with both **BehaviorTree.CPP** and **py_trees** from a
single desktop app.

- **Design & edit** — build trees visually, or open your project's existing trees.
- **Live debugging** — see each node's status update tick-by-tick as the tree runs.
- **Breakpoints** — pause execution on a node to inspect what's happening.
- **Blackboard & ports** — watch values read/written as the tree ticks.
- ⏺**Record & replay** — capture a run and step through it later, no robot needed.
- **Two engines** — BehaviorTree.CPP (ZMQ/Groot2) and py_trees (ROS 2).
